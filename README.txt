# 🏦 Bank Loan Analysis Dashboard

## 📌 Project Overview
This project analyzes bank customer loan and payment behavior using Excel, Power BI, and Tableau. The goal is to identify payment patterns and credit risk based on home ownership.

---

## 🎯 Objectives
- Analyze customer payment behavior
- Create KPI: Days Since Last Payment
- Compare payment trends by home ownership
- Identify high-risk customer segments

---

## 📂 Dataset Information

### Dataset : Customer and payment Information
- id
- home_ownership
- loan_amount
- loan_status
- last_pymnt_d
- total_payment

---

## 🧮 KPI Created

### Days Since Last Payment
Measures how recent a customer made a payment.

Formula:

Days Since Last Payment = Today - Last Payment Date

---

## 📊 Dashboard Features

- KPI Cards
- Payment Recency Analysis
- Home Ownership Risk Comparison
- Interactive Filters

---

## 🛠 Tools Used

- Excel (Power Query, Pivot Tables)
- Power BI (DAX, Dashboard)
- Tableau (Calculated Fields, Dashboard)

---

## 📈 Key Insights

- Homeowners show better payment discipline
- Renters have higher payment delays
- Payment recency is a strong risk indicator
